# Serenity / AleaBito 核心投资框架

## 一句话

Serenity 的强项不是追热门 ticker，而是从超级周期里寻找"下一层还没被充分定价的瓶颈资产"。

## 核心链条

```text
超级周期
-> 架构变化
-> 新瓶颈/新 chokepoint
-> 关键供应商或错价资产
-> 证据链核验（强制标注等级 + 区分一手/二手）
-> 收入弹性与估值重估
-> 量价/市场认知反馈
-> 推荐、观察或否决
-> 反证清单
-> 适配投资者画像（A 股优先、市值偏好、持仓规则）
```

## 六阶段研究动作

1. **标的发现**
   - 从 AI capex、光通信、半导体、机器人、航天、电网、有色金属等大周期出发。
   - 问题不是"哪个股票热"，而是"如果趋势继续推进，哪里会卡住"。
   - A 股优先：先在 A 股中寻找瓶颈受益者，再考虑港股通和 ETF。

2. **信息触发**
   - 财报、订单、客户合作、产能、监管文件、行业会议、产品路线图。
   - 信息必须放进供应链或资本结构里解释，不能只复述新闻标题。
   - 所有信息必须标注证据等级和一手/二手来源。

3. **位置研究**
   - 判断公司到底处在直接受益、间接受益、普通供应商、关键 chokepoint、还是纯概念蹭热点。
   - 核心问题：客户是否绕不开？产品是否被架构变化放大？竞争对手是否稀缺？
   - 中国优势维度：国产替代进度、本土强势程度、海外依赖风险。

4. **深度推演**
   - 看 TAM 扩张、收入 pipeline、毛利率、产能爬坡、客户绑定、可比公司市值锚。
   - Serenity 常用"路径型估值"，不是精确 DCF：如果市场换一种理解方式，估值能否重估。
   - 适配市值偏好：中盘/大盘优先，小盘需更强 thesis。

5. **量价反馈**
   - 看板块联动、无新闻 selloff、北向资金变化、成交量、peer 反应、媒体/社区认知扩散。
   - 价格不是独立信号；价格 + 基本面是否变化 + 市场认知才是信号。
   - A 股特有：关注龙虎榜、北向资金、融资融券变化。

6. **推荐与反证**
   - 推荐必须说明：为什么现在值得研究/买入观察，什么事实会让 thesis 失效。
   - 强信念必须配强反证，不要只写 bullish story。
   - 具体评分使用 `recommendation-scoring.md`，不要只凭直觉给 Recommend。
   - 推荐必须包含持仓建议（仓位、止损、止盈、周期）。

## 推荐等级

- **Recommend / High conviction**: 有明确超级周期、具体 chokepoint、可核验证据、尚未充分定价、清楚催化剂。市值在优先区间。
- **Recommend / Medium conviction**: thesis 清楚，但证据链或估值弹性仍需补强。
- **Watchlist**: 有 Serenity 式结构，但缺少关键外部验证或入场催化。
- **Avoid / Needs proof**: 主要靠叙事、概念、名字相似、社媒热度或不可核验客户关系。

## 六维评分总览

正式推荐前必须评分：

1. 大需求浪潮
2. 具体瓶颈
3. 未充分定价弹性
4. 证据质量
5. 市场反馈
6. 反证清楚

每项 0-4 分，总分 24 分。分数不是数学答案，而是强制研究者逐项说明证据、缺口和降级原因。

## 常见误用

- 把"参与 AI"当成 chokepoint。
- 把 Serenity 自述目标价当成事实。
- 忽略小票流动性、融资、稀释风险。
- 用图形梗替代证据链。
- 推荐时只写 bull case，不写最强反证。
- 把"国产替代概念"等同于"国产替代已实现"。
- 在 A 股投资者场景下推荐不可直接参与的海外标的而不提供替代方案。
