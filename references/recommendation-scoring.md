# Serenity 推荐评分矩阵 — A 股定制版

这个文件用于展开 `SKILL.md` 里的推荐条件。每次给推荐前，先完成六维评分；不要用一句"符合 Serenity 框架"带过。

评分采用 0-4 分制：

- **4 分**：证据强，一手资料充分，和 Serenity 框架高度匹配。
- **3 分**：逻辑强，有可核验证据，但仍有关键假设。
- **2 分**：方向有吸引力，但证据、时点或估值仍不够。
- **1 分**：主要是叙事、类比或弱线索。
- **0 分**：不符合，或存在明确反证。

## 1. 大需求浪潮

判断这个标的背后是否有真实超级周期，而不是短期热词。

### 必查问题

- 需求来自哪里：AI capex、数据中心、光通信、半导体国产替代、机器人量产、航天发射、电网投资、有色金属供需，还是其他周期？
- 这个需求是否已经进入预算、订单、capex、产能规划、政策文件或客户行为？
- 需求是一次性事件，还是未来 1-3 年能持续传导？
- 这个公司是否直接暴露在需求浪潮中，还是只靠概念沾边？
- A 股特有：是否有政策催化（产业政策、专项基金、国产替代目标）？

### 强证据

- 公司或客户公告明确提到 capex、订单、需求扩张、长期协议。
- 行业龙头财报 / 投资者材料反复确认该方向。
- 多个 peer 同时出现收入、订单或产能改善。
- 政策文件明确支持（如"十四五"规划、产业基金、国产替代目标）。

### 弱证据

- 只有社媒热度或新闻标题。
- 只有"AI/半导体/机器人"等标签，但业务收入里看不到。
- 需求存在，但和该公司关系很间接。

### 评分指引

- **4**：真实超级周期 + 多个一手来源 + 公司直接受益 + 政策支持。
- **3**：周期真实，公司有明确暴露，但仍需验证收入弹性。
- **2**：周期真实，但公司关联较弱或时点不清。
- **1**：主要是叙事或概念。
- **0**：需求不存在、已衰退，或公司与周期无关。

## 2. 具体瓶颈

判断公司是否控制一个无法轻易绕开的 chokepoint。

### 必查问题

- 瓶颈到底是什么：材料、衬底、光源、模块、产能、认证、监管文件、专利、合同？
- 客户是否能绕开？替代供应商有多少？切换成本高不高？
- 这个瓶颈是否会被下一代架构放大？
- 这是物理瓶颈、商业瓶颈、监管瓶颈，还是国产替代瓶颈？
- 中国在这个瓶颈上的位置：全球领先 / 本土强势 / 追赶验证 / 概念参与 / 证据不足？

### 强证据

- 客户公告、合作协议、设计导入、供应认证、监管文件、产品路线图。
- 产能紧张、供给集中、长期交付周期。
- 公司产品是系统放量的必要组件，而不是普通可替代供应。
- 国产替代认证进度有客户公告或行业验证。

### 弱证据

- 只说"参与产业链"或"国产替代概念"。
- 客户关系来自推测，没有公告或财报支持。
- 产品可以被多家成熟供应商快速替代。

### 评分指引

- **4**：明确 chokepoint，客户难绕开，证据一手且直接，中国有优势。
- **3**：瓶颈较清楚，但替代关系或客户绑定需补证。
- **2**：处在相关链条，但是否 bottleneck 不确定。
- **1**：只是概念参与者。
- **0**：没有瓶颈，或已被反证。

## 3. 未充分定价弹性

判断市场是否仍按旧叙事理解公司，以及重估空间是否足够。

### 必查问题

- 市值、收入、估值倍数和 peer 相比是否仍低？
- 市场是否仍把公司当旧业务、周期股、小供应商或普通硬件公司？
- 如果 thesis 成立，收入、毛利率、订单、估值倍数能否明显跳档？
- 当前股价是否已经充分反映主要利好？
- 市值是否在偏好区间（中盘/大盘优先）？

### 强证据

- 中/大盘值，覆盖少，业务转折还未进入共识。
- 新客户/新产品/新订单可能显著改变收入结构。
- peer 已被重估，但该公司还没被同等理解。

### 弱证据

- 股票已经大涨，估值已经按最乐观情景定价。
- 弹性只来自目标价想象，没有收入路径。
- 公司频繁融资，股权稀释抵消重估。

### 评分指引

- **4**：市场明显低估，且收入/估值跳档路径清晰。
- **3**：仍有重估空间，但部分预期已进入价格。
- **2**：有弹性，但估值或股价已经不便宜。
- **1**：主要靠情绪推动。
- **0**：明显过度定价或基本面不支持重估。

## 4. 证据质量

判断 thesis 是否建立在可核验资料上。**所有证据必须标注等级和一手/二手来源。**

### 必查问题

- 是否有公司公告、交易所文件、财报、电话会、投资者材料、客户新闻稿？
- 证据是当前的，还是旧资料？
- 是否能区分事实、推断、社区转述、Serenity 自述？
- 关键假设是否至少有两类来源交叉验证？
- 一手来源和二手来源是否已明确区分？

### 强证据

- 一手文件直接支持核心 thesis [A|一手]。
- 多个独立来源相互印证。
- 管理层给出订单、产能、客户、路线图或财务指引。

### 弱证据

- 只有截图、社区帖子、tracker、匿名消息 [C|二手]。
- 只引用券商目标价或盈利预测。
- 核心客户、收入、产能都没有一手证据。

### 评分指引

- **4**：一手证据充分，且直接支持核心 thesis，来源标注完整。
- **3**：证据较强，但仍有 1-2 个关键假设需要补证。
- **2**：有一些可靠证据，但不足以强推荐。
- **1**：主要靠二手资料，一手证据缺失。
- **0**：证据缺失或被一手资料反驳。

## 5. 市场反馈

判断市场是否开始验证或反驳这个 thesis。

### 必查问题

- 价格、成交量是否对相关信息有反应？
- peer 是否同步变化？
- A 股特有：北向资金、融资融券、龙虎榜是否出现异常？
- 媒体、社区、机构报告是否开始讨论同一条链？
- 市场反馈是健康重估，还是短线拥挤？

### 强证据

- 公司和 peer 因相关催化同步反应。
- 成交量放大但 thesis 未完全进入主流共识。
- 下跌时基本面没变，可能出现错杀窗口。
- 北向资金持续流入相关板块。

### 弱证据

- 只有单日拉升，没有新信息。
- 只有社媒喊单，没有成交结构或 peer 验证。
- 过度拥挤，流动性无法支撑后续进入。

### 评分指引

- **4**：市场反馈开始验证 thesis，且未明显过热。
- **3**：反馈积极，但需警惕拥挤或短线波动。
- **2**：反馈混合，仍需等待催化。
- **1**：反馈主要来自情绪。
- **0**：市场反馈明显反驳 thesis。

## 6. 反证清楚

判断风险是否被充分识别，且能被跟踪。

### 必查问题

- 哪个事实会直接推翻 thesis？
- 客户、合同、产能、监管、技术路线、估值、资金链、稀释里最大风险是什么？
- 国产替代进展是否可能不达预期？
- 海外供应商是否可能推出替代方案或新认证？
- 风险是否可通过公告、财报、价格、交付、客户文件持续跟踪？
- 如果风险发生，推荐会如何降级？

### 强证据

- 明确列出 thesis 失效条件。
- 风险有可观测指标和时间窗口。
- bear case 不是敷衍，而是能真正挑战推荐。

### 弱证据

- 只写"有波动风险"。
- 不知道什么会证明自己错。
- 风险不可跟踪，或发生后已无法退出。

### 评分指引

- **4**：反证明确、可跟踪、能指导降级。
- **3**：主要反证清楚，但部分风险仍模糊。
- **2**：知道大风险，但缺少监控指标。
- **1**：风险泛泛而谈。
- **0**：无法说清 thesis 如何失效。

## 总分到推荐

| 总分 | 默认结论 | 限制 |
|---:|---|---|
| 20-24 | Recommend / High conviction | 证据质量和反证清楚都必须 >= 3 |
| 16-19 | Recommend / Medium 或 Watchlist / High priority | 若证据质量 < 3，默认 Watchlist |
| 11-15 | Watchlist | 等待更强证据或更好价格 |
| 0-10 | Avoid / Needs Proof | 只保留观察，不推荐 |

硬性降级规则：

- 证据质量 < 2：不能 Recommend。
- 反证清楚 < 2：不能 High conviction。
- 具体瓶颈 < 2：不能按 Serenity 框架推荐。
- 未充分定价弹性 < 2：最多 Watchlist，除非短期事件驱动非常明确。
- 发现核心事实被一手资料反驳：直接 Avoid 或 Needs Proof。
- 标的完全依赖海外市场且无 A 股/港股通/ETF 替代：降级处理。
