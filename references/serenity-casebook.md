# Serenity 案例库 — A 股适配版

这些案例用于类比，不是自动买入信号。每个案例标注 A 股对标和投资者画像适配。

## RPI / Raspberry Pi

- **模式**：AI agent 叙事 -> 低成本边缘 / 开发者硬件 -> 小市值上市公司高弹性。
- **为什么出圈**：Bloomberg / Reuters 将股价异动与 Serenity 的 "Fun Trade Idea" 联系起来。
- **可复用经验**：同一需求冲击对不同市值公司的影响不同；小公司可能比大公司更敏感。
- **风险**：媒体驱动的动量不等于长期盈利能力。
- **A 股对标**：瑞芯微、全志科技（边缘 AI 芯片）；中科创达（边缘 AI 软件）
- **投资者画像适配**：市值偏小，属于限制级别；需注意流动性风险。

## AXTI / AXT Inc.

- **模式**：AI 数据中心扩张 -> 光互连 / 硅光 -> InP 衬底和上游材料瓶颈。
- **Serenity-style thesis**：公司同时出现在衬底和源材料两层瓶颈里，市场可能低估战略稀缺性。
- **适合类比**：材料、衬底、晶圆、特种组件 chokepoint。
- **关键核验**：真实份额、客户路径、中国 / 出口管制风险、产能、毛利率、替代材料。
- **A 股对标**：云南锗业（锗材料）、有研新材（靶材）、沪硅产业（硅片）
- **投资者画像适配**：材料瓶颈 + 中国优势方向，符合中国优势偏重。

## SIVE / Sivers Semiconductors

- **模式**：AI 数据中心带宽 / 功耗约束 -> CPO / LRO / 光链路 -> 外部激光器和光子组件。
- **外部锚点**：Sivers 曾公告与 Jabil 合作开发面向 AI 数据中心的 1.6T 可插拔光收发器模块。
- **适合类比**：和可信合作方绑定的小型 photonics 供应商。
- **关键核验**：收入贡献、量产时间、客户集中度、融资稀释、流动性。
- **A 股对标**：中际旭创（光模块龙头）、新易盛（光模块）、源杰科技（光芯片）、太辰光（光器件）
- **投资者画像适配**：光通信是核心聚焦行业，中际旭创/新易盛属大盘/中盘，高度适配。

## RKLB / Rocket Lab

- **模式**：公开监管文件 -> 推断事件时间表 -> 市场可能过度定价延迟。
- **thesis 类型**：事件驱动。
- **适合类比**：FCC / FAA / FDA / 合同 / 采购文件提前暴露时间线的机会。
- **关键核验**：文件解读是否正确、事件是否延迟、商业化兑现距离、市场是否已定价。
- **A 股对标**：中国卫星（卫星制造）、航天电器（航天连接器）、火炬电子（航天电容）
- **投资者画像适配**：航天是核心聚焦行业；A 股标的多属中盘，适配度好。需注意军用订单的不透明性。

## GOOGL / META 的 Charizard-style 大盘股案例

- **模式**：高质量大盘股因 capex 或财报担忧回撤 -> 复苏 thesis 被 meme TA 包装。
- **适合类比**：大型科技股的短期叙事错杀。
- **关键核验**：估值是否已经反映复苏、capex 拖累、监管风险、增长持续性。
- **A 股对标**：宁德时代（新能源回撤后趋势交易）、中芯国际（半导体国产替代）
- **投资者画像适配**：大盘股 + 趋势交易风格，高度适配。

## NBIS 与 neocloud / AI infrastructure

- **模式**：AI 算力需求 -> 替代云 / neocloud 产能 -> 小/中市值收入弹性。
- **适合类比**：非显性 mega-cap 的 AI infrastructure 供应商。
- **关键核验**：已签约算力、供电、GPU 融资、利用率、客户质量、债务 / 稀释。
- **A 股对标**：寒武纪（AI 芯片）、海光信息（GPU）、工业富联（AI 服务器）
- **投资者画像适配**：AI 基建是核心聚焦行业，工业富联属大盘，高度适配。

## A 股特有案例

### 中际旭创 / 光通信瓶颈

- **模式**：AI 算力扩张 -> 800G/1.6T 光模块需求 -> 全球光模块龙头受益。
- **Serenity-style thesis**：光模块是 AI 数据中心不可绕开的瓶颈节点，中际旭创在全球高端光模块份额领先。
- **中国优势**：全球领先（光模块整机制造），但光芯片仍部分依赖海外。
- **适合类比**：中国在整机制造有优势、但上游核心器件仍需国产替代的产业链。
- **关键核验**：下一代技术路线（CPO vs 可插拔）、客户集中度、毛利率趋势、光芯片国产替代进度。
- **投资者画像适配**：大盘股 + 光通信聚焦 + 中国优势，高度适配。

### 北方华创 / 半导体设备国产替代

- **模式**：美国出口管制 -> 半导体设备国产替代加速 -> 设备龙头受益。
- **Serenity-style thesis**：出口管制创造了不可逆的国产替代需求，设备是瓶颈中的瓶颈。
- **中国优势**：本土强势（政策 + 客户 + 工程），但在最先进制程设备上仍追赶。
- **适合类比**：出口管制驱动的国产替代机会。
- **关键核验**：客户验证进度、先进制程突破时间、海外竞争者替代可能性。
- **投资者画像适配**：大盘股 + 半导体聚焦 + 国产替代，高度适配。

## 否决经验

- 纯 meme setup 可以作为注意力交易，但不够支撑研究型推荐。
- 好的 Serenity-style 推荐必须有真实 chokepoint，不能只有有趣图形。
- 如果最强证据只是"X 上很多人兴奋"，下调到 Watchlist 或 Avoid。
- "国产替代概念"不等于"国产替代已实现"——必须有客户认证、收入、份额等证据支撑。
- A 股投资者不可直接参与的海外标的，必须提供 ETF 或港股通替代方案。
