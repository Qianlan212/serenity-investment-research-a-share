# Industry Chain Research Template — A 股定制版

Use for sector, supply-chain, chokepoint, "产业革命", "中国位置", "国产替代", or "按上面的思路分析" requests.

## Output Structure

1. **一句话结论**
   - Say whether this is a structural technology/supply-chain shift, a cyclical price move, or an unproven concept.
   - Say China's position in one sentence: 全球领先 / 本土强势 / 追赶验证 / 概念参与 / 证据不足.

2. **为什么是产业变化**
   - Start from demand or architecture change.
   - Explain what old architecture/material/process is being replaced.
   - Explain why the bottleneck appears now.
   - 标注中国政策催化和产业规划（如有）。

3. **技术路线图**
   - Break the chain into materials, components, equipment, process, reliability, customers.
   - Mark which nodes are commodity, which are chokepoints.
   - 每个节点标注中国位置和证据等级。

4. **全球玩家路线图**
   - Separate high-end spec setters, scale manufacturers, equipment/material suppliers, and research institutions.
   - Distinguish official product, sample, pilot, LVM, HVM, and customer-qualified status.
   - 标注 A 股对标公司（如有）。

5. **中国位置地图**
   - For each chain node: 中国优势 / 中国短板 / 代表玩家（A 股代码优先） / evidence grade / verification status.
   - 标注国产替代进度：已替代 / 部分替代 / 追赶中 / 未起步。
   - Avoid turning this into a concept-stock list unless the user asks for tickers.

6. **垄断判断**
   - Use `monopoly-framework.md`.
   - State "global monopoly / local substitution strength / chasing validation / evidence insufficient".
   - 强调中国优势维度：国产替代、本土强势。

7. **A 股标的映射**
   - 按产业链节点映射 A 股标的。
   - 海外标的标注港股通/ETF 参与方式。
   - 标注市值区间和行业聚焦匹配度。

8. **关键反证**
   - What would downgrade the thesis to cyclical restocking?
   - What would show the bottleneck was bypassed?
   - What would show overseas players still control the high-end node?
   - 国产替代是否可能不达预期？

9. **后续研究清单**
   - Company filings, capacity, customer qualification, product specs, yield, ASP, margin, and capex.
   - A 股特有：互动易回复、机构调研纪要、产业政策跟踪。

## Cycle vs Structural Check

Always label each node:

| Type | Signal |
|---|---|
| 周期品 | Inventory, commodity price, utilization, broad capacity, weak differentiation |
| 结构性瓶颈 | Narrow spec window, yield, customer qualification, long switching cycle, concentrated know-how |
| 混合 | Commodity base, but high-end grades are chokepoints |
